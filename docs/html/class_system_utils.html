Detailed Description

Utility class providing system information and hardware diagnostics for ESP32.

This class provides static methods to retrieve various system information including CPU temperature, memory usage, chip details, and formatting utilities for uptime and byte sizes. All methods are static, making this a utility class that doesn't require instantiation.

Note
This class uses a private constructor to prevent instantiation
