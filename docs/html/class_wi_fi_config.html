Detailed Description

Manages WiFi connection configuration and persistence.

This class handles WiFi credentials, connection parameters, and access point mode settings. It provides methods for loading/saving configuration from ESP32 Preferences and managing connection timing.

Key features:

  • Persistent storage of WiFi credentials
  • Configurable connection parameters
  • Access Point mode support
  • Connection timing management
